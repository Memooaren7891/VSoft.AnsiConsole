  document.documentElement.classList.add('spinners-js-ready')

  })

# Spinners reference

`TSpinnerKind` enumerates 90 built-in spinner styles, ported from
Spectre.Console (which ports
[`cli-spinners`](https://github.com/sindresorhus/cli-spinners)). Use them
with [Status](../live/status.md), as a `Widgets.SpinnerColumn` inside
[Progress](../live/progress.md), or directly via `Widgets.Spinner`.

## Picking a spinner

```pascal
AnsiConsole.Status
  .WithSpinner(TSpinnerKind.Dots)
  .Start('working...', proc);

// or a one-off renderable
AnsiConsole.Write(Widgets.Spinner(TSpinnerKind.Earth));
```

## Unicode vs ASCII

Many spinners use Unicode glyphs. When the active console doesn't support
Unicode, a Unicode-only spinner falls back to the simple `Line` set
(`-`, `\`, `|`, `/`) so the animation still works. ASCII-native spinners
(`Ascii`, `Line`, `Pipe`, `Binary`, `Balloon`, etc.) keep their own
frames regardless.

```pascal
Widgets.Spinner(TSpinnerKind.Earth)        // Unicode (default)
Widgets.Spinner(TSpinnerKind.Earth, False) // forces ASCII fallback
```

The **Unicode** column below marks which kinds need a Unicode-capable
terminal — these are the ones that fall back to `Line` when
`unicode=False`. ✓ = Unicode required, – = ASCII-safe.

## Random spinner

For variety in a long-running CLI, pick one from the well-behaved subset:

```pascal
spinner := AnsiConsole.RandomSpinner;
```

`RandomSpinner.Pick` excludes wide-emoji spinners that mis-cell on
legacy hosts; `RandomSpinner.Make(unicode)` returns a ready-to-use
`ISpinner`.

## Custom spinners

Build one from a list of frames + a per-frame interval (ms):

```pascal
custom := Widgets.Spinner(
            TArray<string>.Create('(>    )', '( >   )', '(  >  )',
                                  '(   > )', '(    >)',
                                  '(   < )', '(  <  )', '( <   )', '(<    )'),
            100);

AnsiConsole.Status
  .WithSpinner(custom)
  .Start('working...', proc);
```

The frame list cycles with wrap-around; intervals shorter than the
terminal refresh rate are clamped.

## API reference

- [`TSpinnerKind`](https://github.com/VSoftTechnologies/VSoft.AnsiConsole/blob/main/source/Live/VSoft.AnsiConsole.Live.Spinners.pas) — the full enum.
- `Widgets.Spinner(kind)` — build an `ISpinner` from a kind.
- `Widgets.Spinner(kind, unicode)` — explicit Unicode handling.
- `Widgets.Spinner(frames, intervalMs)` — custom frame list.
- `AnsiConsole.RandomSpinner` — random pick from the safe subset.
- `ISpinner` — interface (`Frames`, `Frame(index)`, `IntervalMs`).
